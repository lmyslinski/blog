Are we trading our hard earned intelligence for convenience?

I've been doing all of my coding work with the help of AI since the early Copilot days. A lot has already been said about the topic, so I'll just summarize what the consensus seems to be:

- AI makes mundane tasks faster but usually fails on more complex tasks or codebases
- the success of using AI is highly dependent on the nature of work - great at spitting our crud apps, not so much at shader optimization
- Recent studied have shown that despite feeling faster, the actual development speed has decreased







The pragmatic engineer has also conducted a study which found out that some rockstar engineers are having "the best time of their lives" using agentic coding tools. Even if that's true, I don't think this holds in the long term.

There are a number of "holy shit dude, that's awesome!" moments when you're going into AI coding. For me, the first copilot was such as experience. Then, there was Cursor which took it a step further with Composer / Agent mode. I could now delegate and implement moderately complex tasks! Finally, there was Claude Code, which is till the pinnacle of what we have available right now. You can plan and implement entire apps using natural language, how is that not fantastic?

Unfortunately, the honeymoon phase doesn't last that long.

<Not quite my tempo/>

As you start increasing the workloads you're delegating to AI, you're noticing the cracks more and more often. Even if everything is *technically correct*, the code rarely looks as if you had written it out by hand. 

I don't want to talk about the code quality aspect, you've likely experienced this yourself. 

I simply stopped enjoying my work. The prompt-wait-correct loop is a very different experience from actual programming.
